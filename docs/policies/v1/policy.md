## 1. 회원

### 1.1. 로그인/ 회원가입

- **카카오 로그인/ 회원가입 지원**
- 서비스는 회원만 이용 가능
- 개인정보처리방침, 서비스이용약관 동의 후 회원가입 가능
- **로그아웃 지원**
    - 서비스 로그인 상태만 종료 (카카오 계정 로그아웃은 하지 않음)

### 1.2. 회원 정보 - 이름

- **회원가입 시 사용자 이름 수집**
    - 카카오 이름이 5자를 초과하는 경우: 초과분 절사
    - 카카오 이름에 한글이 아닌 문자가 포함된 경우: 해당 문자 제외
    - 카카오 이름에 한글이 없는 경우: 회원가입 단계에서 이름 입력
- 최대 5자의 한글로 구성, 중복 허용
    - 한글이 아닌 문자(영어, 중국어, 특수문자, 공백 등) 사용 불가
- 수정 가능

### 1.3. 회원 탈퇴

- 즉시 탈퇴 처리, 회원 정보 hard delete
- **자산 처리**
    - 미체결 주문 취소
    - 현금 폐기
    - 모든 종목의 보유 주식은 탈퇴 시점의 보유 수량 유지
        - 해당 주식은 각 종목의 발행주식 총수에 포함되며, 이후 거래 불가
- **상장한 종목 처리**
    - 종목과 사용자의 연결 해제
    - 종목과 관련된 모든 정보 유지
    - 종목 거래 가능
- **콘텐츠 처리**
    - 모든 콘텐츠 (공시, 뉴스, 댓글) 유지
- **리그 결과 처리**
    - 종료 전 탈퇴 시: 최종 순위 산정 및 결과 보관 대상에서 제외
    - 종료 후 탈퇴 시: 확정된 결과를 유지하며, 표시 이름을 ‘탈퇴한 사용자’로 변경

## 2. 리그

### 2.1. 리그 생성 및 초대

- **리그 생성**
    - 방장이 리그 이름 지정, 상장 완료 시 생성 완료
    - 대기실 생성 및 공통 초대 코드 1개 생성
    - 초대 코드 공유를 통해 타 사용자 초대
    - 대기실 생성 이후 7일 내에 리그가 시작되지 않는 경우 대기실 및 참여코드 만료
- **초대 코드**
    - 영문 대문자와 숫자 7자리
    - 시작 전(대기실) 리그 사이에서 중복 불가
    - 리그 시작 또는 대기실 만료 시 코드 폐기, 폐기된 코드는 다른 리그에 재발급 가능
    - 입력 시 대소문자 구분 없음
- **리그 이름**
    - 최대 12자, 모든 문자 사용 가능
    - 타 리그와 중복 허용
- **리그 개수 제한**
    - 동시 참여 가능한 리그는 최대 5개 (대기실 + 진행 중인 리그)
        - 종료된 방은 동시 참여 리그 수 산정에서 제외
    - 대기실 생성 및 참여 시 제한 검증

### 2.2. 대기실

- **사용자 구분**
    - 방장: 해당 리그를 생성한 사용자
    - 참여자: 해당 리그의 대기실에 진입하여 상장을 마친 사용자 (방장 포함)
        - 상장 관련 정책은 ‣  참고
    - 대기자: 해당 리그의 대기실에 진입하였으나, 상장을 마치지 않은 사용자
    - 대기실에 진입한 사용자는 상장 완료 여부에 따라 대기자 또는 참여자로 구분 (방장도 상장을 완료하면 참여자)
    - 그 외 사용자는 리그와 무관
- **대기자 및 참여자 수 제한 (3~10)**
    - 참여자 3명 도달 시 리그 시작 가능
    - 참여자 + 대기자 수는 최대 10명, 10명 도달 시 추가 입장 불가
    - 대기자가 1명이라도 존재하는 경우 리그 시작 불가
- **대기실 내 방장 권한**
    - 대기실 퇴장, 리그 이름 수정, 리그 삭제, 참여자 삭제, 리그 시작 가능
    - 방장과 참여자, 대기자의 권한은 대기실에서만 상이하며, 리그 시작 이후로는 동일한 권한 보유
- **대기실 내 참여자 권한 (방장 포함)**
    - 대기실 입장, 퇴장, 자신의 종목 수정 가능
    - 리그 시작 이후에는 종목명 수정 불가
- **방장 위임**
    - 리그 시작 전 방장이 대기실 퇴장 진행 시 권한 위임
    - 참여자 중 상장을 완료한 순서로 새 방장 지정
    - 다음 참여자가 없는 경우: 대기실 삭제

### 2.3. 리그 시작 및 운영

- **리그 시작**
    - 방장 포함 3명 이상의 참여자 상장 완료 및 대기자 없음 → 방장이 시작 버튼 클릭 시 리그 시작
    - 리그 시작 권한은 방장에게만 부여
    - 모든 사용자의 자산 배분이 완료된 동일한 시장 상태에서 거래 개시
    - 리그 시작 이후에는 리그에서 퇴장 불가
- **운영 기간**
    - 방장이 시작 버튼을 클릭한 시각의 KST 날짜에 7일을 더한 날 오전 9시 종료
        - 종료 시각 계산식: `시작의 KST 날짜 + 7일, 09:00 KST`
        - 단, 리그 시작 시간이 당일 오전 12시 이상 오전 9시 미만인 경우, 당일 오전 9시까지의 시간은 거래일 계산에 포함하지 않음
          (해당 시간을 사용자에게는 1일차로 표시)
    - 종료일 변경 및 조기 종료 불가
- **리그 종료**
    - 종료 시각부터 리그 결과 페이지만 접근 가능
    - 리그 내의 기타 페이지 접근 불가

### 2.4. 시장

- 방마다 독립적인 시장 운영
- 해당 방에 상장된 모든 종목 거래 가능
- **거래 시간 및 거래일**
    - 리그 진행 중 주말과 공휴일을 포함하여 24시간 거래 가능
    - 매일 오전 9시 KST에 거래일 1일씩 증가
        - 거래일 범위: 해당일 오전 9시 이상부터 다음 날 오전 9시 미만까지
    - 오전 9시에 직전 거래일의 종가 확정 및 새 거래일의 기준가 적용
    - 리그 종료 시각에 주문 접수와 체결 종료
- **시장 정보**
    - 종목별 현재가, 기준가, 상한가, 하한가, 기준가 대비 등락액·등락률, 거래량 제공
    - 시초가: 모든 종목의 최초 가격인 1주당 10,000원
    - 현재가: 최신 체결가
        - 첫 체결 전에는 시초가 적용
    - 상·하한가 관련 정책은 ‣  참고
    - 종가: 거래일의 마지막 체결가
        - 해당 거래일의 거래량이 0이면 기준가 적용
    - 기준가: 직전 거래일 종가
        - 최초 거래일은 시초가 적용
    - 등락률 계산식: `(현재가 - 기준가) / 기준가 × 100`
    - 거래량: 실제 체결 수량의 합계

### 2.5. 리그 결과

- **자산 평가 대상**
    - 종료 시각 직전까지 체결된 거래를 결과에 포함
    - 미체결 주문 전체 취소
- **종료 평가 가격**
    - 마지막 거래일의 거래량가중평균가 (VWAP) 사용
        - 종료 평가 가격 계산식: `Σ(체결 가격 × 체결 수량) / Σ(체결 수량)`
    - 마지막 거래일(8거래일)의 누적 체결량이 500주 미만인 경우 종료에 가까운 과거 체결부터 추가
        - 최소 평가 거래량 500주는 발행량 5,000주의 10%
        - 누적 체결량 500주 도달 시까지 평가 범위 확대
    - 리그 전체 거래량이 500주 미만인 경우 전체 체결 사용
    - 리그 전체에서 체결이 없는 종목은 시초가로 평가
- **최종 총자산 및 순위**
    - 최종 총자산 계산식: `최종 현금 + Σ(각 종목 보유 수량 × 해당 종목 종료 평가 가격)`
        - 원 미만 절사
    - 자사주를 포함한 최종 총자산 기준으로 순위 산정
        - 총자산이 같은 경우 공동 순위 표시
    - 화면에서는 원 단위 표시
    - 최종 순위 및 참여자별 현금, 주식 종목별 보유 수량 및 평가액, 총자산 공개
- **기록 보관**
    - 리그 종료 시점부터 최종 결과 페이지를 제외한 해당 리그 기록 전체 접근 불가
    - 최종 결과 페이지 영구 보관

## 3. 공시·뉴스

### 3.1. 공시

- **공시**: 상장자가 자신의 일상을 자기 종목에 공유하는 글
- **제한**
    - 작성 횟수 무제한
    - 제목 최소 1자 최대 30자, 본문 최소 1자 최대 300자
    - 이미지 JPEG(.jpg/.jpeg), PNG 형식으로 최대 4개 첨부 가능
    - 수정 불가
- **뉴스 생성**
    - 공시 1건을 바탕으로 공시 기반 AI 뉴스 1개 생성
    - 뉴스 생성 실패 시에도 공시 원문 유지, 수동 재시도 가능
- **반응**
    - 사용자들은 공시에 호재와 악재 버튼을 통해 반응 가능
    - 사용자의  반응이 기사에 영향을 미치지 않음
- **삭제**
    - 공시 삭제 후에도 기존 공시 기반 AI 뉴스 유지
    - 공시 삭제 시에도 뉴스 생성 자동 재시도는 실행, 수동 재시도는 불가
    - 이미 체결된 거래 유지

### 3.2. 뉴스 - 공시 기반 AI 뉴스

- 모든 뉴스는 하나의 종목에 연결, 종목 1개에 뉴스 여러 개 연결 가능 (일대다 관계)
- 공시 기반 AI 뉴스는 하나의 공시에 연결 (일대일 관계)
- **제한**
    - 제목 최대 30자, 본문 최대 100자 제한
    - 이미지 없이 발행
    - 삭제 불가
- **생성**
    - 공시 원문에 있는 사실을 기준으로 1개의 기사 작성
    - AI가 판단하여 공시 내용에 말이 되는 문장이 없는 경우 뉴스를 생성하지 않음
    - 뉴스 발행 시 호재 또는 악재 여부를 함께 판단
- **재시도**
    - 자동 재시도
        - 최초 생성 실패 후 자동 재시도 최대 2회
        - 공시 삭제 여부와 관계없이 수행
    - 수동 재시도
        - 자동 재시도 모두 실패 시 공시 작성자에게 버튼 제공하여 수동 재생성 가능
        - 수동 재생성 요청에도 자동 재시도 최대 2회 정책 동일 적용
        - 공시가 삭제되지 않았으며, 리그가 진행 중인 경우에만 가능

### 3.3. 댓글 (공통)

- 댓글 정책은 콘텐츠 전역에 동일하게 적용
- **제한 및 표시**
    - 게시물에 최대 100자의 댓글 작성 가능, 이미지 첨부 불가
    - 계정 이름 표시
    - 대댓글 작성 불가
- **삭제**: 댓글 작성자 본인의 댓글 삭제 가능

## 4. 자산 관리

### 4.1. 종목 상장

- **상장**
    - 로그인 상태이고, 새로운 리그에 참여할 수 있는 상태의 사용자가 종목 이름과 소개를 작성한 후 저장하는 것
    - 각 사용자는 하나의 리그에서 하나의 종목만 상장 가능, 종목 이름 및 소개 필수 입력
- **종목 이름**
    - 최대 12자, 글자, 숫자, 공백만 사용 가능 (특수문자·이모지 불가)
        - 앞뒤 공백이 있는 경우 제거, 제거한 글자수로 제한 확인
    - 같은 리그 내에서 종목 이름 중복 불가
    - 대기실일 경우에만 종목 이름 변경 가능 (리그 시작 후 변경 불가)
- **종목 소개**
    - 최대 50자, 모든 문자 사용 가능
    - 리그 시작 이후에도 수정 가능

### 4.2. 초기 자산 배분

- 초기 자산은 리그 시작 시 일괄 배분, 배분이 완료되지 않으면 거래 불가
- **주식 배분**
    - 모든 종목의 시초가는 1주당 10,000원
    - 종목마다 주식 5,000주 발행
        - 상장자에게 2,500주 배분
        - 나머지 2,500주는 상장자를 제외한 참여자에게 균등 배분
        - 균등 배분 후 남은 주식은 해당 종목의 상장자에게 추가 배분 (홀수 고려)
- **현금 배분**
    - 총자산은 시초가 기준 1억 원으로 통일
    - 초기 주식 배분 완료 후, 주식 평가액을 제외한 나머지를 현금으로 지급
        - `초기 주식 평가액 = 배분받은 전체 주식 수 × 10,000원`
        - `초기 현금 = 1억 원 - 초기 주식 평가액`

### 4.3. 총자산 집계

- **총자산 계산식**: `총자산 = 현금 + Σ(각 종목 보유 수량 × 평가 가격)`
    - 평가 가격은 호출하는 쪽이 지정 (진행 중: 현재가, 리그 종료 시: 종료 평가 가격)
    - 자사주를 포함하여 계산
    - 원 미만 절사
- 참여자별 현금, 종목별 보유 수량과 평가액, 총자산을 함께 반환
- 리그가 호출 (진행 중 순위, 리그 결과)

### 4.4. 자산 조회

- 로그인한 사용자는 참여 중인 리그에서 본인의 자산만 조회 가능
- 본인 자산은 실시간 조회 가능 (자산이 변동되면 화면에 반영)
- **조회 항목**
    - 보유 현금, 보유 주식 평가 금액, 총자산, 총자산 평가 손익
    - 보유 종목별 종목 이름, 보유 수량, 자사주 여부, 평가 금액, 평가 손익, 수익률
- 평가 가격은 현재가, 총자산은 총자산 집계 계산식을 따름
- **매입 금액**
    - 보유 종목별로 보유 수량 전체를 사는 데 든 금액, 이동평균법 적용
    - 초기 배분 주식의 매입 금액: `배분 수량 × 시초가 10,000원`
    - 체결 시 갱신 규칙은 주문 가능 자산 및 정산 참고
- **평가 손익 및 수익률**
    - `평가 금액 = 보유 수량 × 현재가`
    - `평가 손익 = 평가 금액 - 매입 금액`
    - `수익률(%) = 평가 손익 ÷ 매입 금액 × 100`, 소수점 둘째 자리에서 반올림하여 첫째 자리까지 표시
        - 음수는 절댓값 기준으로 반올림 (예: -12.35% → -12.4%)
    - 자사주도 같은 방식으로 계산
- **총자산 평가 손익**
    - `총자산 평가 손익 = 총자산 - 1억 원`
    - 이미 매도해 현금으로 바뀐 손익을 포함

## 5. 자산 거래

### 5.1. 가격제한폭

- 해당 거래일의 **기준가 대비 ±30% 범위**에서 주문 및 체결 가능
- **100원 호가 단위를 반영하여 가격 범위 계산**
    - `가격제한폭 금액 = 기준가 × 30%에서 100원 미만 절사`
    - `상한가 = 기준가 + 가격제한폭 금액`
    - `하한가 = 기준가 - 가격제한폭 금액`
- 매일 **오전 9시 KST**에 새 기준가와 가격 범위 적용

### 5.2. 주문

- `지정가 주문`과 보호 조건이 있는 `시장가 주문` 제공
- 주문 수량은 1주 단위의 양의 정수
- 주문 가격은 100원 이상의 100원 단위
- **지정가 주문**
    - 사용자가 가격과 수량 지정
    - 매수는 지정 가격 이하, 매도는 지정 가격 이상에서 체결
    - 미체결 잔여 수량은 대기 주문으로 유지
- **시장가 주문**
    - 사용자가 수량 지정
    - 주문 접수 시 최우선 상대 호가를 기준으로 **5% 이내**에서 즉시 체결
        - 매수: 최우선 매도 호가보다 최대 5% 높은 가격까지
        - 매도: 최우선 매수 호가보다 최대 5% 낮은 가격까지
    - 당일 상·하한가와 100원 호가 단위 함께 적용
    - 보호 범위 안에서 체결 가능한 수량을 체결하고 잔여 수량 취소
    - 체결 가능 수량이 0이면 전량 취소

### 5.3. 주문 가능 자산 및 정산

- **주문 가능 자산**
    - 매수는 사용 가능한 현금, 매도는 매도 가능한 주식 수량 범위에서 접수
    - 예약 자산을 제외한 잔액과 수량으로 추가 주문 가능 여부 계산
    - 주문에 필요한 자산이 부족하면 주문 거절
- **매수 주문의 현금 예약**
    - 지정가: `지정 가격 × 주문 수량`
    - 시장가: `보호 조건 내 최고 체결 가능 가격 × 주문 수량`
- **매도 주문은 주문 수량만큼 주식 예약**
- **체결 시 실제 체결 금액과 수량으로 즉시 정산**
    - 매수: 현금 감소 및 주식 증가
    - 매도: 주식 감소 및 현금 증가
    - 매수 체결 가격이 예약 기준 가격보다 낮으면 차액 예약 해제
- **체결 시 매입 금액 갱신 (이동평균법)**
    - 매수: `매입 금액 = 기존 매입 금액 + 체결 가격 × 체결 수량`
    - 매도: `매입 금액 = 기존 매입 금액 × 매도 후 보유 수량 ÷ 매도 전 보유 수량`, 원 미만 절사
    - 보유 수량이 0이 되면 매입 금액은 0, 이후 매수는 0부터 다시 계산
- **취소·만료**
    - 미체결 잔여 수량에 해당하는 예약 자산 해제
    - 취소와 체결이 동시에 요청된 경우 먼저 확정된 처리 결과 적용

### 5.4. 체결

- **체결 원칙**
    - 체결 조건**:** 매수 가격이 매도 가격 이상이면 체결 가능
    - 체결 우선순위
        - 매수 주문은 높은 가격 우선
        - 매도 주문은 낮은 가격 우선
        - 같은 가격에서는 먼저 접수된 주문 우선
    - 체결 가격**:** 먼저 접수되어 대기 중이던 주문의 가격 적용
    - 체결 수량**:** 주문 수량 전체 또는 일부 체결 가능
- **자전거래 금지**
    - 조건: 같은 계정의 매수·매도 주문이 서로 체결될 차례가 된 경우
    - 신규 주문의 미체결 잔여 수량 취소
    - 기존 대기 주문 및 이미 체결된 부분 유지

### 5.5. 자사주 최소 유지분

- **자사주 최소 유지분은 1,000주**
- 자사주 매도 가능 수량 계산식
    - `max(0, 자사주 보유 수량 - 기존 매도 주문 예약 수량 - 1,000주)`
- 주문 접수와 체결 처리에서 최소 유지분 보호

### 5.6. 미체결 주문 관리

- **만료**
    - 지정가 주문의 미체결 잔여 수량은 다음 오전 9시 KST에 모두 만료
    - 이미 체결된 부분 유지
    - 미체결 잔여 수량에 예약된 현금과 주식 해제
- **변경**
    - 사용자는 자신의 주문 중 미체결 잔여 수량 취소 가능
    - 주문 가격·수량 변경은 기존 주문 취소 후 신규 주문 제출로 처리
        - 신규 주문은 새 접수 시각을 기준으로 시간 우선순위 적용
- 오전 9시 정각 이후 접수된 주문은 새 거래일 주문으로 처리
- 리그 종료 시 모든 미체결 주문 취소 및 예약 자산 해제
