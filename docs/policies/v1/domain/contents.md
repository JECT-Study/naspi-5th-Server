# 공시·뉴스 정책 (v1)

## 공시

- **공시**: 상장자가 자신의 일상을 자기 종목에 공유하는 글
- **제한**
    - 작성 횟수 무제한
    - 제목 최소 1자 최대 30자, 본문 최소 1자 최대 300자
    - 이미지 JPEG(.jpg/.jpeg), PNG 형식으로 최대 4개 첨부 가능
    - 각 이미지가 50MB를 초과할 수 없음
    - 수정 불가
- **뉴스 생성**
    - 공시 1건을 바탕으로 공시 기반 AI 뉴스 1개 생성
    - 뉴스 생성 실패 시에도 공시 원문 유지, 수동 재시도 가능
- **반응**
    - 사용자들은 공시에 호재와 악재 버튼을 통해 반응 가능, 두 반응 중 하나만 등록 가능
    - 사용자의  반응이 기사에 영향을 미치지 않음
- **삭제**
    - 공시 작성자 본인만 삭제 가능
      - 삭제 후 해당 공시와 달린 댓글 조회 불가
    - 공시 삭제 후에도 기존 공시 기반 AI 뉴스 유지
    - 공시 삭제 시에도 뉴스 생성 자동 재시도는 실행, 수동 재시도는 불가
    - 이미 체결된 거래 유지

## 뉴스 - 공시 기반 AI 뉴스

- 모든 뉴스는 하나의 종목에 연결, 종목 1개에 뉴스 여러 개 연결 가능 (일대다 관계)
- 공시 기반 AI 뉴스는 하나의 공시에 연결 (일대일 관계)
- **제한**
    - 제목 최대 30자, 본문 최대 100자 제한
    - 이미지 없이 발행
    - 삭제 불가
- **생성**
    - 공시 원문에 있는 사실을 기준으로 1개의 기사 작성
    - AI가 판단하여 공시 내용에 말이 되는 문장이 없는 경우 뉴스를 생성하지 않음
    - 뉴스 발행 시 호재 또는 악재 여부를 함께 판단
- **재시도**
    - 자동 재시도
        - 최초 생성 실패 후 자동 재시도 최대 2회
        - 공시 삭제 여부와 관계없이 수행
    - 수동 재시도
        - 자동 재시도 모두 실패 시 공시 작성자에게 버튼 제공하여 수동 재생성 가능
        - 수동 재생성 요청에도 자동 재시도 최대 2회 정책 동일 적용
        - 공시가 삭제되지 않았으며, 리그가 진행 중인 경우에만 가능

## 뉴스 - 제보 기반 AI 뉴스

- **제보**: 참여자가 다른 참여자의 종목(대상 종목)에서 일어난 일상적인 사건을 알리는 글
    - 자기 종목에는 제보할 수 없음 (자기 종목은 공시로 작성)
    - 상장자가 탈퇴한 종목에도 제보 가능
    - 본문 최소 1자 최대 300자, 제목 없음
    - 이미지 JPEG(.jpg/.jpeg), PNG 형식으로 최대 4개 첨부 가능, 각 이미지가 50MB를 초과할 수 없음
    - 작성 횟수 무제한, 수정 불가
    - 제보는 저장하고, 저장 후 제보 기반 AI 뉴스를 생성 (생성 실패 시에도 제보 원문 유지)
    - 제보 원문 조회, 삭제, 뉴스 수동 재생성 정책은 별도로 정한다
- 제보 기반 AI 뉴스는 하나의 제보에 연결, 제보 1건당 뉴스 최대 1개 생성
- 발행된 제보 기반 AI 뉴스는 공시 기반 AI 뉴스와 함께 종목별 뉴스·통합 피드에 표시
- **제한**
    - 제목 최대 30자, `{종목 이름}, 내용` 형식 (쉼표 뒤 공백 한 칸)
    - 본문 최대 100자, 본문 끝에 `제보자 {제보자 이름}` 형식으로 출처 명시
- **생성**
    - 대상 종목 이름, 제보자 이름, 제보 본문, 첨부 이미지를 바탕으로 1개의 기사 작성 (과거 공시 요약은 사용하지 않음)
    - AI 1회 호출로 생성 가능 여부 판단과 기사 작성을 함께 수행
    - 실제 경제 뉴스처럼 진지하고 건조한 문체를 유지하되, 일상적인 사건을 경제·경영 관점에서 과장하여 표현
    - 제보에 없는 사실이나 사건을 임의로 창작하지 않음
    - 본문과 이미지를 함께 활용하되, 이미지에서 확인할 수 없는 사실은 추측하지 않음
    - 뉴스 발행 시 호재 또는 악재 여부를 함께 판단
- **미생성**
    - 제보에서 대상 종목에 관한 기사 소재를 파악할 수 없는 경우 뉴스를 생성하지 않음
    - 짧은 문장, 오타, 낮은 중요도는 미생성 사유가 아님
    - 미생성 사유는 `제보 내용 부족`
    - 미생성은 시스템 오류에 따른 생성 실패와 구분
    - 뉴스 생성 전에 제보자가 탈퇴했으면 생성 실패로 처리
- **재시도**
    - 최초 요청을 포함하여 최대 3회 시도 (공시 기반 AI 뉴스의 자동 재시도 최대 2회와 동일)
    - AI 호출 오류, 응답 처리 오류, 출력 검증 실패 시 재시도
    - 미생성(`제보 내용 부족`)은 재시도하지 않음
- **출력 검증**
    - 제목·본문 글자 수 제한 준수
    - 제목이 `{종목 이름}, `(종목 이름, 쉼표, 공백)으로 시작하고 그 뒤에 내용이 있음
    - 본문이 `제보자 {제보자 이름}`으로 끝남
    - 필수 항목(제목, 본문, 호재·악재) 존재 및 출력 형식 준수

## 댓글 (공통)

- 댓글 정책은 콘텐츠 전역에 동일하게 적용
- **제한 및 표시**
    - 게시물에 최대 100자의 댓글 작성 가능, 이미지 첨부 불가
    - 계정 이름 표시
    - 대댓글 작성 불가
- **삭제**: 댓글 작성자 본인의 댓글 삭제 가능
