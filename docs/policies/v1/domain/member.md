# 회원 정책 (v1)

> 이 파일은 `policy.md`에서 생성된다. 직접 수정하지 말고 `policy.md`를 고친 뒤 `/sync-docs` (또는 `python3 scripts/sync-policy.py`)를 실행한다.
> 모듈: `member` · 원본: policy.md §1.1, §1.2, §1.3, §1.4
> 탈퇴 처리는 여러 모듈에 걸쳐 있음: 주문 취소(order), 현금 폐기·보유 유지(asset), 종목 연결 해제(market), 콘텐츠 유지(contents), 결과 처리(league)

## 로그인/ 회원가입

- **카카오 로그인/ 회원가입 지원**
- 서비스는 회원만 이용 가능
- 개인정보처리방침, 서비스이용약관 동의 후 회원가입 가능

## 회원 정보 - 이름

- **회원가입 시 사용자 이름 수집**
    - 카카오 이름이 5자를 초과하는 경우: 초과분 절사
    - 카카오 이름에 한글이 아닌 문자가 포함된 경우: 해당 문자 제외
    - 카카오 이름에 한글이 없는 경우: 회원가입 단계에서 이름 입력
- 최대 5자의 한글로 구성, 중복 허용
    - 한글이 아닌 문자(영어, 중국어, 특수문자, 공백 등) 사용 불가
- 수정 가능

## 회원 정보 - 이메일

- 회원가입 시 사용자 이메일 수집

## 회원 탈퇴

- 즉시 탈퇴 처리, 회원 정보 hard delete
- **자산 처리**
    - 미체결 주문 취소
    - 현금 폐기
    - 모든 종목의 보유 주식은 탈퇴 시점의 보유 수량 유지
        - 해당 주식은 각 종목의 발행주식 총수에 포함되며, 이후 거래 불가
- **상장한 종목 처리**
    - 종목과 사용자의 연결 해제
    - 종목과 관련된 모든 정보 유지
    - 종목 거래 가능
- **콘텐츠 처리**
    - 모든 콘텐츠 (공시, 뉴스, 댓글) 유지
- **리그 결과 처리**
    - 종료 전 탈퇴 시: 최종 순위 산정 및 결과 보관 대상에서 제외
    - 종료 후 탈퇴 시: 확정된 결과를 유지하며, 표시 이름을 ‘탈퇴한 사용자’로 변경
