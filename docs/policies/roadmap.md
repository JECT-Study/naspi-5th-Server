## 1. 계정

### 1.1. 로그인/회원가입

- 카카오 로그인만 지원
- 로그인하지 않은 사용자는 랜딩페이지만 접근 가능, 이외의 페이지 및 기능 접근 불가
- 개인정보처리방침, 서비스이용약관 동의 후 회원가입 가능

### 1.2. 사용자 이름

- 최대 5자의 한글로 구성, 중복 허용
- 한글이 아닌 문자(영어, 중국어, 특수문자, 공백 등) 사용 불가
- 회원가입 시 카카오 이름을 가져와 사용
    - 카카오 이름이 5자를 초과하는 경우: 초과분 절사
    - 카카오 이름에 한글이 아닌 문자가 포함된 경우: 해당 문자 제외
    - 카카오 이름에 한글이 없는 경우: 모달을 통해 이름 입력
- 수정 가능

### 1.3. 계정 탈퇴

- 자산 처리
    - 탈퇴자의 미체결 주문 취소 후 예약 자산 해제
    - 현금과 모든 종목의 보유 주식을 봇이 승계
        - 승계 자산의 기본 배분
            - 현금은 1원 단위, 주식은 종목별 1주 단위로 배분
            - `봇별 기본 배분량 = 승계 자산 수량 ÷ 3의 정수부`
            - 세 봇에 기본 배분량을 동일하게 배분
        - 잔여 자산 배분
            - 기본 배분 후 남은 현금, 주식을 1단위씩 순환 배분
            - 마지막 잔여 자산을 받은 봇의 다음 봇부터 다음 배분 시작
            - 현금 및 종목별 주식의 순환 배분 차례를 각각 관리
    - 자사주 최소 유지분 제한 해제, 승계한 주식은 봇이 전량 매도 가능
        - 최초 배분 순서: 유동성 봇 → 뉴스 반응 봇 → 추세 반응 봇
- 종목 유지
    - 종목과 관련된 모든 정보 유지
    - 종목 정보, 다른 참여자의 보유 주식, 가격, 체결 기록 유지
    - 종목 상세 및 거래 제공, 비활동 판정과 봇 거래 유지
- 콘텐츠 처리
    - 모든 콘텐츠 (공시, 뉴스, 커뮤니티, 댓글) 유지
- 결과 처리
    - 탈퇴자는 리그 결과 공개 및 보관 대상에서 제외

## 2. 방

### 2.1. 방 생성 및 초대

- 방장을 포함하여 최소 3명부터 최대 10명까지 참여 가능
    - 참여 인원 3명 도달 시 리그 시작 가능
    - 참여 인원 10명 도달 시 추가 상장 불가
- 방장이 방 이름 지정 및 상장 완료 시 대기실 생성 및 방별 공통 초대 코드 1개 생성
    - 방 이름은 최대 20자로 구성, 모든 문자 사용 가능, 중복 허용
    - 대기실 생성 후, 게임 시작 7일동안 진행 안 될 시 대기실 및 참여코드 만료
- 대기실에서 상장을 완료한 사용자만 참여 확정

### 2.2. 방 개수 제한

- 동시 참여 가능한 방은 대기실과 진행 중인 방을 합하여 최대 5개
- 종료 후 결과만 보관하는 방은 동시 참여 방 수 산정에서 제외
- 대기실 생성 시와 참여 시 제한 확인

### 2.3. 대기실 내 변경 및 방장 권한

- 모든 참여자는 대기실에 입장, 퇴장, 자신의 종목 수정 가능
- 방장은 리그 시작 전까지 방 이름 수정, 방 삭제, 이미 상장한 참여자 삭제, 방 시작 가능
- 리그 시작 시 참여자 명단 고정
- 방장과 참여자의 권한은 대기실에서만 상이하며, 리그 시작 이후로는 동일한 권한 보유
- 리그 시작 전 방장이 대기실을 나가는 경우 방장 권한 위임
    - 방장은 나가기 전 상장을 완료한 참여순으로 새 방장으로 지정
    - 다음 참여자가 없는 경우: 대기실 종료

### 2.4. 방별 정보 분리

- 현금, 주식, 공시, 뉴스, 커뮤니티, 순위의 방별 분리
- 자산은 해당 방에서만 사용 가능

## 3. 종목 상장

### 3.1. 상장

- 상장: 로그인 상태이고 새로운 방에 참여할 수 있는 상태의 사용자가 종목 이름과 소개를 작성한 후 저장하는 것
- 사용자당 종목은 1개만 상장 가능, 종목 이름 및 소개 필수 입력

### 3.2. 종목 이름

- 최대 12자로 구성, 특수문자를 제외한 모든 문자 사용 가능
    - 앞뒤 공백이 있는 경우 제거, 제거한 글자수로 제한 확인
- 같은 방 내에서 종목 이름 중복 사용 불가
- 종목 이름에 사용자 계정 이름의 글자 최소 1자 포함 필수
    - 계정 이름이 ‘김수빈’인 경우: ‘수빈전자’, ‘빈바이오’ 모두 사용 가능
- 상장 이후 계정 이름을 변경해도 기존 종목 이름 유지

### 3.3. 종목 소개

- 최대 50자까지 작성 가능, 모든 문자 사용 가능

## 4. 리그 운영

### 4.1. 리그 시작

- 방장 포함 3명 이상의 참여자 상장 완료 후 방장의 시작 버튼 클릭 시 리그 시작
- 리그 시작 권한은 방장에게만 부여
- 모든 사람과 봇의 자산 배분이 완료된 동일한 시장 상태에서 거래 개시

### 4.2. 운영 기간

- 방장이 시작 버튼을 클릭한 시각의 KST 날짜에 7일을 더한 날 오전 9시 종료
    - 종료 시각 계산식: `시작의 KST 날짜 + 7일, 09:00 KST`
    - 단, 방 개설 시간이 당일 오전 12시 이상 오전 9시 미만인 경우, 당일 오전 9시까지의 시간은 거래일 계산에 포함하지 않는다.
      (해당 시간을 사용자에게는 1일차로 표시)
- 종료일 변경 및 조기 종료 불가

### 4.3. 종료 처리

- 종료 시각부터 리그 결과 페이지만 접근 가능, 방 내의 기타 페이지 접근 불가

## 5. 자산

### 5.1. 초기 자산 및 시장 세팅

- 초기 자산은 리그 시작 시 일괄 배분
    - 모든 사람과 매매봇의 배분 완료 후 거래 개시
    - 배분이 완료되지 않으면 거래 불가
- 사람 참여자의 시작 총자산은 시초가 기준 1억 원으로 통일
- 초기 주식 배분 완료 후, 주식 평가액을 제외한 나머지를 현금으로 지급
    - `초기 주식 평가액 = 배분받은 전체 주식 수 × 10,000원`
    - `초기 현금 = 1억 원 - 초기 주식 평가액`
- 모든 종목의 시초가는 1주당 10,000원
- 종목마다 주식 5,000주 발행
    - 상장자에게 2,500주 배분
    - 나머지 2,500주는 상장자를 제외한 사람 참여자와 매매봇에게 균등 배분
    - 균등 배분 후 남은 주식은 해당 종목의 상장자에게 추가 배분

### 5.2. 본인 자산 조회

- 본인의 자산 실시간(웹소켓, SSE) 조회 가능
- 자산: 전체 현금과 현재가 기준 주식 평가액의 합
    - 예약된 현금과 주식도 자산에 포함, 중복 합산 방지
- 자사주 최소 유지분 1,000주 안내
- 자산별 평가 기준 안내
    - 실시간 자산: 현재가 기준
    - 전날 공개 자산: 종가 기준
    - 종료 결과: 종료 평가 가격 기준

### 5.3. 직전 거래일 참가자 자산 공개

- 매일 오전 9시에 각 참가자의 총자산 공개
    - 전 거래일 종료 시점 기준의 자산
    - 현금과 주식 비중, 개별 보유 종목, 보유 수량 등 세부 내역 비공개
    - 공개 자산 계산식: `해당 시점 전체 보유 현금 + Σ(해당 시점 보유 수량 × 해당 종목 종가)`
- 참가자들의 자산을 실시간으로 표시하지 않으며, 거래일이 바뀔 때마다 업데이트
- 종료일에는 직전 거래일 자산 대신 최종 결과만 공개

## 6. 시장

### 6.1. 시장 구성

- 방마다 독립적인 시장 운영
- 해당 방에 상장된 모든 종목 거래 가능
- 사람과 매매봇이 동일한 시장에서 거래
- 종목별 가격과 거래량은 실제 체결을 기준으로 형성

### 6.2. 거래 시간 및 거래일

- 리그 진행 중 주말과 공휴일을 포함하여 24시간 거래 가능
- 매일 오전 9시 KST에 거래일 1일씩 증가
    - 거래일 범위: 해당일 오전 9시 이상부터 다음 날 오전 9시 미만까지
- 오전 9시에 직전 거래일의 종가 확정 및 새 거래일의 기준가 적용
- 리그 종료 시각에 주문 접수와 체결 종료 (리그 종료 관련 4.2 참고)

### 6.3. 시장 정보

- 종목별 현재가, 기준가, 상한가, 하한가, 기준가 대비 등락액·등락률, 거래량 제공
- 등락률 계산식: `(현재가 - 기준가) / 기준가 × 100`
- 거래량은 실제 체결 수량의 합계
    - 사람 간, 사람과 봇 간, 서로 다른 봇 간 체결 모두 포함
    - 체결 1건의 수량을 한 번만 합산
- 참여자별 종목 보유 수량은 리그 종료 후 공개

### 6.4. 차트

- 실제 체결 데이터를 기반으로 차트(캔들, 라인 선택 가능)와 거래량 제공
- 체결 지점과 마지막 체결 시각 표시
- 거래량이 0인 구간은 직전 가격을 유지하여 표시
- 차트 및 호가창은 실시간 연동 지원

## 7. 거래

### 7.1. 가격 정의

- 시초가: 모든 종목의 최초 가격인 1주당 10,000원
- 현재가: 최신 체결가
    - 첫 체결 전에는 시초가 적용
- 종가: 거래일의 마지막 체결가
    - 해당 거래일의 거래량이 0이면 기준가 적용
- 기준가: 직전 거래일 종가
    - 최초 거래일은 시초가 적용
- 사람과 봇의 모든 실제 체결을 가격 산정에 포함

### 7.2. 가격제한폭

- 해당 거래일의 기준가 대비 ±30% 범위에서 주문 및 체결 가능
- 사람과 봇에게 동일한 가격제한폭 적용
- 100원 호가 단위를 반영하여 가격 범위 계산
    - `가격제한폭 금액 = 기준가 × 30%에서 100원 미만 절사`
    - `상한가 = 기준가 + 가격제한폭 금액`
    - `하한가 = 기준가 - 가격제한폭 금액`
- 매일 오전 9시 KST에 새 기준가와 가격 범위 적용
- 상한가와 하한가에서도 상대 주문과 체결 가능

### 7.3. 주문 방식 및 단위

- 지정가 주문과 보호 조건이 있는 시장가 주문 제공
- 주문 수량은 1주 단위의 양의 정수
- 주문 가격은 100원 이상의 100원 단위
- 지정가 주문
    - 사용자가 가격과 수량 지정
    - 매수는 지정 가격 이하, 매도는 지정 가격 이상에서 체결
    - 미체결 잔여 수량은 대기 주문으로 유지
- 시장가 주문
    - 사용자가 수량 지정
    - 주문 접수 시 최우선 상대 호가를 기준으로 5% 이내에서 즉시 체결
        - 매수: 최우선 매도 호가보다 최대 5% 높은 가격까지
        - 매도: 최우선 매수 호가보다 최대 5% 낮은 가격까지
    - 당일 상·하한가와 100원 호가 단위 함께 적용
    - 보호 범위 안에서 체결 가능한 수량을 체결하고 잔여 수량 취소
    - 체결 가능 수량이 0이면 전량 취소

### 7.4. 체결 원칙

- 사람과 매매봇의 주문에 동일한 가격·시간 우선 원칙 적용
    - 매수 주문은 높은 가격 우선
    - 매도 주문은 낮은 가격 우선
    - 같은 가격에서는 먼저 접수된 주문 우선
- 체결 가능한 상대 주문 중 우선순위에 따라 매칭
- 매수 가격이 매도 가격 이상이면 체결 가능
- 체결 가격은 먼저 접수되어 대기 중이던 주문의 가격 적용
- 주문 수량 전체 또는 일부 체결 가능
- 사람과 봇 모두 자전거래 금지
    - 같은 계정의 매수·매도 주문이 체결될 차례가 되면 신규 주문의 미체결 잔여 수량 취소
    - 기존 대기 주문과 이미 체결된 부분 유지

### 7.5. 주문 가능 자산 및 정산

- 매수는 사용 가능한 현금, 매도는 매도 가능한 주식 수량 범위에서 접수
- 예약 자산을 제외한 잔액과 수량으로 추가 주문 가능 여부 계산
- 매수 주문의 현금 예약
    - 지정가: `지정 가격 × 주문 수량`
    - 시장가: `보호 조건 내 최고 체결 가능 가격 × 주문 수량`
- 매도 주문은 주문 수량만큼 주식 예약
- 주문에 필요한 자산이 부족하면 주문 거절
- 체결 시 실제 체결 금액과 수량으로 즉시 정산
    - 매수: 현금 감소 및 주식 증가
    - 매도: 주식 감소 및 현금 증가
    - 매수 체결 가격이 예약 기준 가격보다 낮으면 차액 예약 해제

### 7.6. 자사주 거래 제한

## 8. 매매봇

#### 8.3.1. 유동성 봇

- 실행 시점

- 판단 기준
    - 기준 가격

    - 가격

        - `매도 가격 = 기준 가격 + 가격 차`
    - 수량

        - 목표 수량 0주: 해당 방향의 기존 잔량 취소
    - 체결 후

    - 만료
        - 거래일 전환 및 리그 종료 시 미체결 주문 취소

    - 동일 주문 요청 ID의 중복 접수 시 기존 접수 결과 반환
    - 접수 결과 미확인 시 기존 주문 이력 확인 후 상태 확정
- 리그 종료
    - 봇의 주문 제출 및 체결 종료
    - 실행 예정인 매매 작업 취소
    - 미체결 주문 취소

## 9. 공시

### 9.1. 공시 작성 및 게시

- 공시: 상장자가 자신의 일상을 자기 종목에 공유하는 글
- 제한
    - 작성 횟수 무제한
    - 제목 최대 30자, 본문 최대 300자
    - 이미지 JPEG(.jpg/.jpeg), PNG 형식으로 최대 4개 첨부 가능
    - 수정 불가
- 게시 완료 즉시 공개
    - 해당 종목의 종목 소개
    - 해당 방의 피드
- 공시 1건을 바탕으로 AI 뉴스 1개 생성
    - 뉴스 생성 실패 시에도 공시 원문 유지

### 9.2. 공시 삭제

- 공시 삭제 후에도 기존 뉴스 유지, 같은 종목에 공시 삭제 사실을 알리는 기사 1개 추가 발행
- 공시 삭제 시에도 뉴스 생성 자동 재시도는 실행, 수동 재시도는 불가
- 이미 체결된 거래 유지

### 9.3. 공시 반응

- 사용자들은 공시에 호재와 악재 버튼을 통해 반응 가능
- 사용자의  반응이 기사에 영향을 미치지 않음

### 9.4. 댓글

- 공시 게시물에 최대 200자의 댓글 작성 가능, 이미지 첨부 불가
- 익명 처리, 같은 게시물 안에서 작성자별 익명 표시 이름 고정
- 게시물 및 댓글 작성 시점에 해당 종목 보유 시 주주 배지 표시
    - 작성 시점 기준으로 주주 배지 고정
    - 이후 해당 종목 매도 시에도 기존 게시물 및 댓글의 주주 배지 유지
- 댓글 작성자 본인의 댓글 삭제 가능

## 10. 뉴스

### 10.1. 뉴스 공통 정책

- 모든 뉴스는 하나의 종목에 연결, 종목 1개에 뉴스 여러 개 연결 가능 (일대다 관계)
- 뉴스의 종류
    - 공시 기반 AI 뉴스: 상장자의 공시를 기반으로 AI가 생성하여 발행하는 뉴스
    - 사용자 작성 AI 뉴스: 상장자 외의 참여자가 작성하며, AI 윤문을 거쳐 발행하는 뉴스
    - 일일 요약 AI 뉴스: 매일 오전 9시에 해당 종목의 전 거래일 공시 및 차트를 기반으로 AI가 생성하여 발행하는 뉴스
    - 사용자 활동 뉴스
        - 비활동 악재 뉴스: 직전 거래일에 공시를 업로드하지 않은 사용자의 종목에 발행하는 악재 뉴스
        - 자사주 매매
        - 공시 삭제
- 제한
    - 제목 최대 30자, 본문 최대 100자 제한
    - 사용자 작성 뉴스는 이미지 JPEG(.jpg/.jpeg), PNG 형식으로 최대 1개 첨부 가능,
      그 외 뉴스는 이미지 없이 발행
    - 수정 불가
    - 삭제 불가 (예외: 사용자 작성 AI 뉴스는 글 쓴 사용자가 삭제 가능)
- 뉴스 발행 시 호재 또는 악재 여부를 함께 판단
    - 일일 요약 뉴스의 경우, 호재 또는 악재를 판단하여 표시하지 않고, ‘요약’으로 표기
    - 비활동 악재 뉴스의 경우, 악재로 고정

### 10.2. 공시 기반 AI 뉴스

- 공시 원문에 있는 사실을 기준으로 1개의 기사 작성
- AI가 판단하여 공시 내용에 말이 되는 문장이 없는 경우 뉴스를 생성하지 않음
- 재시도
    - 최초 생성 실패 후 자동 재시도 최대 3회
    - 자동 재시도 모두 실패 시 공시 작성자에게 ‘뉴스 다시 생성’ 버튼 제공하여 수동 재생성 가능
    - 수동 재생성 요청에도 자동 재시도 최대 3회 정책 동일 적용
    - 이미 생성된 기사 유지, 부족한 기사만 추가하여 공시당 총 3개 생성
    - 삭제되지 않은 공시와 진행 중인 리그에서만 재생성 가능

### 10.3. 사용자 작성 뉴스

- 다른 참여자의 종목에 뉴스 작성 가능
- 자신의 종목에 관한 일상은 공시로 공유
- 작성한 사용자의 계정 이름이 뉴스 내에 명시
- AI를 통한 뉴스 형식 윤문
- 작성자의 AI 윤문 결과 사전 확인 후 게시

### 10.4. 일일 요약 뉴스

- 매일 오전 9시에 종목별 거래일당 기사 1개 생성
    - input 데이터: 해당 거래일의 공시와 댓글 반응, 실제 체결 기반 시가·고가·저가·종가, 거래량, 기준가 대비 등락률
- 공시 및 체결 여부에 따른 요약 구성
    - 공시와 체결 모두 존재: 소식 및 차트 요약
    - 공시 없이 체결만 존재: 차트 요약 및 ‘새 공시 없음’ 표시
    - 체결 없이 공시만 존재: 소식 요약 및 ‘거래 없음’ 표시
    - 공시 업로드와 체결 모두 없음: 해당 종목의 일일 요약 생략
- 삭제된 공시는 반영하지 않음
- 종료일 오전 9시에는 발행 생략

### 10.5. 비활동 악재 뉴스

- 직전 거래일의 공시 업로드를 기준으로 활동 여부 판정
    - 뉴스, 커뮤니티, 댓글, 호재 악재 버튼, 거래, 로그인은 활동 판정에서 제외
    - 공시를 업로드한 후 삭제했어도 업로드한 것으로 인정
    - 오전 9시 정각 이후 게시한 공시는 새 거래일 활동으로 기록
- 매일 오전 9시, 직전 거래일에 게시 완료된 공시가 0개인 종목에 비활동 악재 뉴스 1개 발행
    - 두 번째 거래일에는 발행하지 않음 (첫 거래일에는 공시 업로드 의무를 두지 않기 위함)
- 종료일 오전 9시에는 발행 생략
- 공시 작성 재개 후에도 기존 비활동 뉴스를 삭제하지 않음

### 10.6. 댓글

- 뉴스 게시물에 최대 200자의 댓글 작성 가능, 이미지 첨부 불가
- 익명 처리, 같은 게시물 안에서 작성자별 익명 표시 이름 고정
- 게시물 및 댓글 작성 시점에 해당 종목 보유 시 주주 배지 표시
    - 작성 시점 기준으로 주주 배지 고정
    - 이후 해당 종목 매도 시에도 기존 게시물 및 댓글의 주주 배지 유지
- 댓글 작성자 본인의 댓글 삭제 가능

## 11. 리그 결과

### 11.1. 자산 평가 대상

- 종료 시각 직전까지 체결된 거래를 결과에 포함
- 미체결 주문 전체 취소

### 11.2. 종료 평가 가격

- 마지막 거래일의 거래량가중평균가 (VWAP) 사용
    - 종료 평가 가격 계산식: `Σ(체결 가격 × 체결 수량) / Σ(체결 수량)`
- 마지막 거래일(8거래일)의 누적 체결량이 500주 미만인 경우 종료에 가까운 과거 체결부터 추가
    - 최소 평가 거래량 500주는 발행량 5,000주의 10%
    - 누적 체결량 500주 이상 도달 시까지 평가 범위 확대
- 리그 전체 거래량이 500주 미만인 경우 전체 체결 사용
- 리그 전체에서 체결이 없는 종목은 시초가로 평가

### 11.3. 최종 총자산 및 순위

- 최종 총자산 계산식: `최종 현금 + Σ(각 종목 보유 수량 × 해당 종목 종료 평가 가격)`
- 자사주를 포함한 최종 총자산 기준으로 순위 산정
    - 총자산이 같은 경우 공동 순위 표시
- 화면에서는 원 단위 표시
- 최종 순위 및 참여자별 현금, 주식 종목별 보유 수량 및 평가액, 총자산 공개
- 매매봇은 최종 리그 결과 순위에 참여자로 포함하지 않음

### 11.4. 기록 보관

- 리그 종료 시점부터 최종 결과 페이지를 제외한 해당 리그 기록 전체 접근 불가
- 최종 결과 페이지 영구 보관
