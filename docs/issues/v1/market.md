### MKT-01 대기자는 자신의 종목 이름과 소개를 작성해 리그에 상장할 수 있다
- Jira: ND-60
- 정책: [market.md#종목-상장](../../policies/v1/domain/market.md#종목-상장)
- 선행: LEA-03
- 내용: 대기실에서 종목 이름·소개 작성 후 저장, `StockListed` 이벤트 발행
- 완료 조건
  - [x] 리그당 1인 1종목, 이름·소개 필수
  - [x] 이름: 앞뒤 공백 제거 후 최대 12자, 글자·숫자·공백만 허용 (특수문자·이모지 불가), 같은 리그 내 중복 불가
  - [x] 소개: 최대 50자
  - [ ] 참여자 10명이면 상장 불가
- 메모: 리그 상태(대기실 여부, 참여자 수) 검증은 league 구현 후 연동한다. 우선 league를 배제하고 상장 규칙만 구현

### MKT-02 참여자는 대기실에서 종목명을, 리그 시작 이후에도 종목 소개를 수정할 수 있다
- Jira: ND-61
- 정책: [market.md#종목-상장](../../policies/v1/domain/market.md#종목-상장)
- 선행: MKT-01
- 완료 조건
  - [ ] 본인 종목만 수정 가능
  - [ ] 종목명은 대기실 상태에서만 수정 가능, 리그 시작 후 불가
  - [ ] 종목 소개는 리그 시작 후에도 수정 가능
  - [ ] MKT-01과 동일한 검증

### MKT-03 시스템은 기준가 대비 ±30%와 100원 호가 단위로 상·하한가를 계산한다
- Jira:
- 정책: [market.md#가격제한폭](../../policies/v1/domain/market.md#가격제한폭)
- 완료 조건
  - [ ] 가격제한폭 금액 = 기준가 × 30%의 100원 미만 절사
  - [ ] 상한가 = 기준가 + 금액, 하한가 = 기준가 - 금액
  - [ ] 경계값 단위 테스트

- 선행: LEA-09, MKT-03

  - [ ] 리그 시작 시 모든 종목 시초가 10,000원, 최초 기준가 = 시초가

### MKT-05 체결이 발생하면 종목의 현재가와 거래량이 갱신된다
- Jira:
- 정책: [market.md#시장](../../policies/v1/domain/market.md#시장)
- 선행: ORD-03, GLB-04
- 내용: `TradeExecuted` 구독
- 완료 조건
  - [ ] 현재가 = 최신 체결가 갱신
  - [ ] 거래일 거래량 = 체결 수량 합계 (체결 1건당 1회 합산)
  - [ ] VWAP 계산용 체결 기록 저장

### MKT-06 거래일이 바뀌면 종목의 종가가 확정되고 새 기준가와 가격 범위가 적용된다
- Jira:
- 정책: [market.md#시장](../../policies/v1/domain/market.md#시장), [#가격제한폭](../../policies/v1/domain/market.md#가격제한폭)
- 선행: LEA-11, MKT-05
- 완료 조건
  - [ ] 종가 = 마지막 체결가, 거래량 0이면 기준가
  - [ ] 새 기준가 = 직전 종가, 새 상·하한가 적용, 거래량 초기화
  - [ ] 거래일 전환과 체결의 순서 보장 (09:00 이전 체결은 이전 거래일)

### MKT-07 리그가 종료되면 종목별 종료 평가 가격이 VWAP로 산정된다
- Jira:
- 정책: [league.md#리그-결과](../../policies/v1/domain/league.md#리그-결과)
- 선행: MKT-05
- 완료 조건
  - [ ] 마지막 거래일 VWAP = Σ(체결가 × 수량) / Σ수량
  - [ ] 마지막 거래일 체결량 500주 미만이면 종료 시각에 가까운 과거 체결부터 500주까지 확대
  - [ ] 리그 전체 500주 미만이면 전체 체결, 체결 없으면 시초가
- 결정 필요: VWAP 결과의 원 미만 처리 (절사/반올림)

### MKT-08 참여자는 리그 내 종목의 현재가, 등락률, 거래량 등 시세를 조회할 수 있다
- Jira:
- 정책: [market.md#시장](../../policies/v1/domain/market.md#시장)
- 선행: MKT-04
- 완료 조건
  - [ ] 리그 내 종목 목록과 종목 상세: 이름, 소개, 현재가, 기준가, 상·하한가, 등락액, 등락률, 거래량
  - [ ] 등락률 = (현재가 - 기준가) / 기준가 × 100
- 결정 필요: 등락률 소수점 자릿수
