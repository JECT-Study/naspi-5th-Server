### MBR-02 사용자는 회원가입 시 카카오 이름을 서비스 이름 규칙에 맞게 자동으로 받는다

- 정책: [member.md#회원-정보---이름](../../policies/v1/domain/member.md#회원-정보---이름)
- 선행: MBR-01
- 완료 조건

  - [X] 한글이 하나도 없으면 이름 입력 필요 상태로 응답

### MBR-06 회원은 즉시 탈퇴할 수 있다
- Jira: ND-9
- 정책: [member.md#회원-탈퇴](../../policies/v1/domain/member.md#회원-탈퇴)

  - 탈퇴 후 리그 참여자(`Player`) 레코드 보존 방식

### MBR-07 회원은 로그아웃할 수 있다
- Jira: ND-63
- 정책: [member.md#로그인-회원가입](../../policies/v1/domain/member.md#로그인-회원가입)
- 선행: MBR-01
- 내용: `POST /api/auth/logout`으로 로그인 세션을 끝낸다. Spring Security 기본 로그아웃이 `SecurityConfig`에 설정되어 있으나 응답 형식·테스트·API 문서가 없다.
- 완료 조건
  - [X] 로그아웃하면 세션(Redis)이 무효화되고 세션 쿠키가 삭제된다
  - [X] 로그아웃 후 로그인이 필요한 API를 호출하면 인증 필요(401, `"003"`)로 응답한다
  - [X] 성공 응답은 공통 응답 형식(`Result`, `code` `"000"`)을 따른다
  - [X] 로그인하지 않은 상태(세션 없음·만료)에서 호출해도 성공으로 응답한다
  - [X] 카카오 계정 로그아웃은 하지 않는다 (서비스 세션만 종료)
  - [X] Swagger에 로그아웃 API 설명이 노출된다
