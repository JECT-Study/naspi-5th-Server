# [회원] member

### MBR-01 사용자는 약관에 동의하고 카카오 계정으로 회원가입·로그인할 수 있다
- Jira: ND-7
- 정책: [member.md#로그인-회원가입](../../policies/v1/domain/member.md#로그인-회원가입)
- 선행: GLB-02
- 내용: 카카오 OAuth 인증, 신규 회원이면 가입 절차, 기존 회원이면 로그인
- 완료 조건
  - [X] 개인정보처리방침·서비스이용약관 동의 없이는 가입 불가
  - [X] 기존 회원 재로그인 시 중복 가입되지 않음

### MBR-02 사용자는 회원가입 시 카카오 이름을 서비스 이름 규칙에 맞게 자동으로 받는다
- Jira: ND-26
- 정책: [member.md#회원-정보---이름](../../policies/v1/domain/member.md#회원-정보---이름)
- 선행: MBR-01
- 완료 조건
  - [ ] 한글이 아닌 문자 제외 후 5자 초과분 절사
  - [ ] 한글이 하나도 없으면 이름 입력 필요 상태로 응답

### MBR-03 카카오 이름에 한글이 없는 사용자는 회원가입 단계에서 이름을 직접 입력할 수 있다
- Jira: ND-28
- 정책: [member.md#회원-정보---이름](../../policies/v1/domain/member.md#회원-정보---이름)
- 선행: MBR-02
- 완료 조건
  - [ ] 최대 5자 한글만 허용 (영어, 한자, 특수문자, 공백 불가)
  - [ ] 이름 중복 허용

### MBR-06 회원은 즉시 탈퇴할 수 있다
- Jira: ND-9
- 정책: [member.md#회원-탈퇴](../../policies/v1/domain/member.md#회원-탈퇴)
- 선행: MBR-01, GLB-04
- 내용: 즉시 탈퇴, 회원 정보 hard delete, `MemberWithdrawn` 이벤트 발행
- 완료 조건
  - [ ] 탈퇴 즉시 재로그인 불가 (재가입은 신규 회원)
  - [ ] 후속 처리 연결: ORD-11(주문 취소), AST-07(자산 처리), MKT-09(종목 연결 해제), LEA-15(결과 처리)
- 결정 필요
  - hard delete 후 남는 콘텐츠(공시, 댓글)의 작성자 표시 방식 (댓글은 계정 이름 표시 정책)
  - 탈퇴 후 리그 참여자(`Participant`) 레코드 보존 방식
